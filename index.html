↥ Restaurar respaldo

Reemplaza los registros actuales de este navegador. Solicita la clave actual del administrador antes de importar. No se conecta con otros equipos.

🔐 Seguridad de administrador

Cambie periódicamente su contraseña. Se guarda un verificador derivado con sal, no la contraseña en texto.

☁️ Sincronización automática con GitHub

Una vez establecida la conexión, cada cambio guardado por el administrador se envía automáticamente al archivo JSON de su repositorio. Los cambios se guardan primero en este navegador. No se modifica el archivo index.html en GitHub.

Seguridad: el JSON de GitHub se cifra antes de subirlo. El token y la clave de cifrado no se guardan en el HTML, en GitHub ni en el almacenamiento local; debe ingresarlos después de volver a abrir la página. Utilice un token de acceso personal de permisos finos, con acceso únicamente a este repositorio y permiso Contents: Read and write. Guarde su clave de cifrado fuera de GitHub: sin ella no podrá recuperar el archivo remoto.

GitHub desconectado. Los cambios siguen guardándose localmente.

Si los datos locales y los de GitHub son distintos, el aplicativo detiene la escritura y pide elegir una versión. Ante conflictos o fallas de Internet, conserva los cambios locales sin sobrescribir datos remotos.

Importante sobre el modo local

La separación entre administrador y lectores se aplica en la interfaz y en las funciones del aplicativo. Un archivo HTML local no proporciona controles de seguridad resistentes ante alguien que tenga acceso directo al almacenamiento o al código del equipo. Mantenga el perfil del administrador protegido, no comparta los respaldos privados y utilice «↗ Consulta» para enviar una copia sin funciones de edición.

Al cambiar de navegador, limpiar los datos del sitio o mover este archivo a otra ruta, los registros locales pueden no estar disponibles. Conserve copias JSON.
